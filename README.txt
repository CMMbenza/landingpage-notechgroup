NOTECH GROUP WEBSITE
====================

Fichiers :
- index.php : page principale
- assets/css/style.css : styles personnalisés et responsive
- assets/js/main.js : menu mobile, filtres portfolio, formulaire mailto
- assets/logo.png : logo fourni
- assets/hero-art.jpg : visuel recadré depuis la maquette fournie

UTILISATION
1. Décompressez le dossier.
2. Ouvrez index.php dans un navigateur, ou envoyez tout le contenu du dossier sur votre hébergement.
3. Pour mettre en ligne : placez index.php et le dossier assets dans public_html (ou le dossier racine du domaine).

À PERSONNALISER AVANT PUBLICATION
- Le numéro WhatsApp/téléphone +243 81 000 00 00 est un exemple : remplacez-le par le numéro officiel.
- Vérifiez l'adresse e-mail contact@notechgroup.com.
- Les liens sociaux et certains liens de projets sont des exemples.
- Le formulaire ouvre l'application e-mail du visiteur (mailto). Pour enregistrer les messages dans une base de données, il faudra connecter un backend PHP ou un service de formulaire.

Le site utilise Bootstrap 5.3.3 et Bootstrap Icons via CDN ; une connexion Internet est nécessaire pour charger ces bibliothèques.
